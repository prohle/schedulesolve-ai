## How to reproduce

```bash
cd backend
.venv/bin/python scripts/solver_audit.py --seeds 0-9 --include-built
```

Raw records: `backend/artifacts/solver_audit.json` and `.csv`.

Statuses are honest by construction: a timeout is `unknown`, never `infeasible`; a greedy-only run is `feasible` unless its incumbent meets the admissible lower bound. A `NO` in the Valid column means a returned timetable violated a hard constraint (a solver bug); `—` means the engine honestly returned no timetable (infeasible/unknown).
